# Работа с учебным проектом

Сначала прочитай README.md. Тема курсовой: «Разработка ИИ-ассистента для генерации и проверки практических заданий для подготовки к экзамену». Проект должен оставаться понятным первокурснику.

## Устройство

- Используются HTML, CSS, JavaScript-модули и Node.js без внешних npm-зависимостей и сборки.
- `dist/` — отслеживаемые исходники интерфейса, не результат сборки. Сохраняй утверждённый графитовый интерфейс с лаймовым акцентом, название «Экзамен+», русский язык и мобильный вид. Главный экран — диалог с заданием, боковая панель — переключение задач. Параметры открываются в диалоге настроек.
- `dist/format.mjs` форматирует формулы локальной KaTeX 0.16.22 из dist/vendor/katex (MIT, лицензия рядом). Сохраняй trust:false, ограничения размера/раскрытий и экранирование ошибок. Код в блоках не форматируется как математика. Эталоны и экспорт остаются исходным текстом. Сервер отдаёт только модуль, CSS и разрешённые WOFF2; CDN и npm-установка не нужны.
- `server.mjs` отвечает за маршруты. `server/provider.mjs` подключает модель; `server/store.mjs` хранит сессии, приватные эталоны и переписку; `server/checker.mjs` выполняет безопасное сравнение ответов. Модели выбираются по серверному реестру в provider.mjs; браузер передаёт только id gemini/qwen, без ключей и адресов.
- Реальные промпты находятся в `prompts/generation.mjs`, `prompts/checking.mjs`, `prompts/explanation.mjs`, `prompts/dialogue.mjs`. Последний определяет намерение свободного сообщения без эталона; развёрнутый ответ затем проверяется отдельно. В интерфейсе одно поле без переключателя «ответ/вопрос». Меняй их отдельно и не объявляй качество улучшенным без проверки.
- `dist/generator.mjs` содержит проверенные шаблоны и справочник тем. `makeTasks` при обычной работе сайта вызывается сервером. `hasTemplates` отделяет исходные три темы от семи дополнительных и custom, которым нужен ИИ. Для custom валидируй customTopic (одна строка, 2–160 символов); `topicName` используется в интерфейсе, истории и экспорте. Сохраняй тему при создании похожего задания. Название передаётся промпту как данные, не как системные инструкции.
- Публичная проекция варианта не должна содержать answer, explanation, proof или исходный ответ модели. Эталон возвращается только при явном показе решения: /solution или kind:solution в /respond после directAction. История/статус не должны раскрывать решения.
- Не исполняй введённый пользователем или моделью код. Математический парсер не использует eval. Числовая проверка не должна засчитывать голое число вместо требуемого доказательства или приравнивать разные Python-контейнеры.
- Чат и задания принадлежат серверной сессии. Чужие идентификаторы не дают доступа к заданиям. Подсказки и контекст чата не включают полный эталон. Полное решение открывается отдельной кнопкой или явной текстовой просьбой, распознанной directAction.
- Хранилище в памяти ограничено; перезапуск очищает историю. Не описывай его как постоянную базу данных.

## Запуск и проверки

- Рекомендуется Node.js 24 LTS. При HTTP_PROXY/HTTPS_PROXY нужен Node.js 24.5+. Не отключай TLS и существующую настройку прокси.
- `npm start` или `npm run dev` автоматически читают необязательный .env и запускают порт 8000. Требуется Node.js 24.5+. Установка npm-пакетов не требуется.
- Для существующего встроенного предпросмотра: `HOST=0.0.0.0 EMBEDDED_PREVIEW=1 npm run dev`. Только этот режим снимает frame-ancestors; для HTTPS-предпросмотра cookie должна работать во встроенном окне. Обычный запуск сохраняет самостоятельную политику.
- Перед завершением изменений генерации, проверки или интерфейса выполняй `npm test`. Python 3 должен быть доступен как `python` для исполнения заранее подготовленных учебных примеров в тестах.
- `npm run test:browser` через scripts/verify-browser.mjs запускает отдельный createApp({settings:{}}) на свободном порту и tests/browser.py (Python Playwright + Chromium). ИИ-сценарии используют явные заглушки. Ручной запуск tests/browser.py также поддерживает TEST_BASE_URL.
- `npm test` и браузерные проверки не должны расходовать API-баланс. `npm run test:llm` отдельно выполняет настоящие операции генерации, проверки развёрнутого ответа и чата. Запускай только в рамках разрешённой пользователем проверки подключения.
- Проверяй реальные математические ответы независимо. Не выдавай тесты с заглушкой или наличие aiAvailable за проверку провайдера. Сохраняй фактические результаты и ограничения в `docs/EXPERIMENTS.md`.

## Подключение модели и размещение

- Текущее рабочее подключение — Google Gemini: https://generativelanguage.googleapis.com/v1beta/openai и gemini-3.1-flash-lite. Локальный игнорируемый `.env.connection.json` с подключением newapi_channel_conn имеет приоритет над LLM_* среды. Сохраняй его, не печатай значения ключей. Предыдущее подключение сохранено в игнорируемом .env.connection.pre-gemini-20261024.json. Google Gemini также выбран по умолчанию в коде. Для прежнего ShareLLM нужно явно задать адрес и модель; SSE-парсер сохранён.
- Основное подключение задаётся LLM_API_KEY. Для второго профиля используются QWEN_API_KEY/QWEN_BASE_URL/QWEN_MODEL или GEMINI_API_KEY/GEMINI_BASE_URL/GEMINI_MODEL. В локальном .env.connection.json допустимы providers.qwen/providers.gemini; не удаляй их при обновлении подключения. Ключи не попадают в браузер, GitHub, архивы, Dockerfile или сообщения.
- Qwen по умолчанию использует qwen3.8-27b: qwen3.8-flash исчез из списка ShareLLM. Для обеих моделей на ShareLLM запрашивается SSE, чтобы получать данные по мере готовности; собирай только delta.content. Отвергай оборванный поток без [DONE], ошибки и finish_reason=length. Обычный JSON-ответ также поддерживается. Не переключай выбранного провайдера скрыто при ошибке. Безопасный числовой answer из JSON нормализуется в строку; пустые поля и небезопасные числа отклоняются.
- Лимит ответа: проверка/чат и одно задание — 2048 токенов; генерация увеличивает его с числом заданий до 8000. Стандартное рассуждение не отключается. Это ограничивает длину ответа, а не доказывает его правильность; при length нужен отказ, а не принятие обрывка.
- Таймаут модели 240 секунд, браузера 250 секунд, проверочного HTTP-запроса 260 секунд. Не сокращай браузерное ожидание ниже серверного. Стандартный режим рассуждения Qwen сохраняется.
- В репозитории хранится текущая серверная версия; архивная автономная версия удалена. Кнопка скачивания на сайте экспортирует условия заданий, а исходники скачиваются через GitHub. Не возвращай устаревший автономный экспорт: скрытые эталоны требуют сервера.
- Не меняй приватность существующего сайта без запроса. Публичное размещение — отдельная операция; инструкция о хостинге не означает фактическую публикацию. Dockerfile должен включать dist, server и prompts. GitHub Pages без Node.js-сервера текущую версию не обслуживает.
