# Работа с проектом

Сначала прочитай README.md. Это учебный прототип курсового проекта первого курса.

## Устройство

- Приложение состоит из HTML, CSS и JavaScript-модулей без внешних зависимостей.
- Исходники интерфейса находятся в dist/. Это отслеживаемые исходные файлы, а не результат сборки.
- dist/generator.mjs содержит шаблонную генерацию заданий, проверку параметров и составление промпта.
- dist/app.mjs управляет интерфейсом, историей и прогрессом в localStorage.
- tests/verify.mjs проверяет математические ответы, Python-примеры и события интерфейса.
- Сохраняй русскоязычный интерфейс и существующий стиль. Меняй стек только по запросу пользователя.

## Запуск и проверка

- Нужны Node.js 18 или новее и Python 3, доступный командой python.
- npm run dev запускает статический сервер на порту 8000. Зависимости устанавливать не требуется.
- Перед завершением изменений генерации или интерфейса выполняй npm test.
- Текущие тесты интерфейса используют адаптер DOM. Они не подтверждают проверку в настоящем браузере.
- Новые математические задания проверяй независимым вычислением или содержательными тестами.

## Языковая модель и доступ

- В текущем прототипе задания создаются локально. Промпт показывается и копируется, но не отправляется языковой модели.
- Не описывай запланированную LLM-интеграцию как уже реализованную.
- При подключении модели храни API-ключ на сервере или в секретах окружения. Проверяй структуру ответа и безопасно отображай полученный текст.
- Сохраняй приватный доступ существующего сайта. Публичное размещение допускается по явному запросу пользователя.
