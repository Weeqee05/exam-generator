# Работа с учебным проектом

Сначала прочитай README.md. Тема курсовой: «Разработка ИИ-ассистента для генерации и проверки практических заданий для подготовки к экзамену». Проект должен оставаться понятным первокурснику.

## Устройство

- Используются HTML, CSS, JavaScript-модули и Node.js без внешних npm-зависимостей и сборки.
- `dist/` — отслеживаемые исходники интерфейса, не результат сборки. Сохраняй утверждённый графитовый интерфейс с лаймовым акцентом, название «Экзамен+», русский язык и мобильный вид. Главный экран — диалог с заданием, боковая панель — переключение задач. Параметры открываются в диалоге настроек.
- `server.mjs` отвечает за маршруты. `server/provider.mjs` подключает модель; `server/store.mjs` хранит сессии, приватные эталоны и переписку; `server/checker.mjs` выполняет безопасное сравнение ответов.
- Реальные промпты находятся в `prompts/generation.mjs`, `prompts/checking.mjs`, `prompts/explanation.mjs`. Меняй их отдельно и не объявляй качество улучшенным без проверки.
- `dist/generator.mjs` содержит проверенные шаблоны и справочник тем. `makeTasks` при обычной работе сайта вызывается сервером.
- Публичная проекция варианта не должна содержать answer, explanation, proof или исходный ответ модели. Эталон возвращает только явный `/solution`. История/статус не должны раскрывать решения.
- Не исполняй введённый пользователем или моделью код. Математический парсер не использует eval. Числовая проверка не должна засчитывать голое число вместо требуемого доказательства или приравнивать разные Python-контейнеры.
- Чат и задания принадлежат серверной сессии. Чужие идентификаторы не дают доступа к заданиям. Подсказки и контекст чата не включают полный эталон. Полное решение открывается отдельной кнопкой.
- Хранилище в памяти ограничено; перезапуск очищает историю. Не описывай его как постоянную базу данных.

## Запуск и проверки

- Рекомендуется Node.js 24 LTS. При HTTP_PROXY/HTTPS_PROXY нужен Node.js 24.5+. Не отключай TLS и существующую настройку прокси.
- `npm start` или `npm run dev` запускает порт 8000. Установка npm-пакетов не требуется.
- Для существующего встроенного предпросмотра: `HOST=0.0.0.0 EMBEDDED_PREVIEW=1 npm run dev`. Только этот режим снимает frame-ancestors; для HTTPS-предпросмотра cookie должна работать во встроенном окне. Обычный запуск сохраняет самостоятельную политику.
- Перед завершением изменений генерации, проверки или интерфейса выполняй `npm test`. Python 3 должен быть доступен как `python` для исполнения заранее подготовленных учебных примеров в тестах.
- `tests/browser.py` использует Python Playwright и Chromium. Запускай на отдельном сервере `createApp({settings:{}})` без настоящего ключа, с `TEST_BASE_URL` нужного адреса. ИИ-сценарии используют явные заглушки.
- `npm test` и браузерные проверки не должны расходовать API-баланс. `npm run test:llm` отдельно выполняет настоящие операции генерации, проверки развёрнутого ответа и чата. Запускай только в рамках разрешённой пользователем проверки подключения.
- Проверяй реальные математические ответы независимо. Не выдавай тесты с заглушкой или наличие aiAvailable за проверку провайдера. Сохраняй фактические результаты и ограничения в `docs/EXPERIMENTS.md`.

## Подключение модели и размещение

- Текущее рабочее подключение — Google Gemini: https://generativelanguage.googleapis.com/v1beta/openai и gemini-3.1-flash-lite. Локальный игнорируемый `.env.connection.json` с подключением newapi_channel_conn имеет приоритет над LLM_* среды. Сохраняй его, не печатай значения ключей. Предыдущее подключение сохранено в игнорируемом .env.connection.pre-gemini-20261024.json. Google Gemini также выбран по умолчанию в коде. Для прежнего ShareLLM нужно явно задать адрес и модель; SSE-парсер сохранён.
- На новом хостинге API-ключ задаётся серверной переменной LLM_API_KEY. Ключи не попадают в браузер, GitHub, архивы, Dockerfile или сообщения.
- Qwen использует SSE; сервер собирает только delta.content. Отвергай оборванный поток без [DONE], ошибки и finish_reason=length. Остальные провайдеры сохраняют обычный JSON-запрос.
- Лимит ответа: проверка/чат и одно задание — 2048 токенов; генерация увеличивает его с числом заданий до 8000. Стандартное рассуждение не отключается. Это ограничивает длину ответа, а не доказывает его правильность; при length нужен отказ, а не принятие обрывка.
- Таймаут модели 240 секунд, браузера 250 секунд, проверочного HTTP-запроса 260 секунд. Не сокращай браузерное ожидание ниже серверного. Стандартный режим рассуждения Qwen сохраняется.
- Старые downloads/praktikum.html и ZIP — архивная автономная версия 0.1. Новые серверные функции туда не экспортируются: скрытые эталоны требуют сервера.
- Не меняй приватность существующего сайта без запроса. Публичное размещение — отдельная операция; инструкция о хостинге не означает фактическую публикацию. Dockerfile должен включать dist, server и prompts. GitHub Pages без Node.js-сервера текущую версию не обслуживает.
