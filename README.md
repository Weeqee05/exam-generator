# exam-generator

Генератор практических заданий для подготовки к экзамену.

«Практикум» — рабочий учебный прототип курсового проекта «Генератор практических заданий для подготовки к экзамену с использованием промпт-инжиниринга».

## Текущие возможности

- Темы: комплексные числа, множества и отношения, основы Python.
- Три уровня сложности и от 1 до 10 заданий в варианте.
- Раскрываемые подсказки, ответы и объяснения.
- Новый вариант, отметка решённых заданий и история последних 20 вариантов.
- Восстановление прогресса в том же браузере через localStorage.
- Составление и копирование промпта с темой, сложностью, количеством заданий и форматом JSON.

Сейчас задания формируются по локальным шаблонам со случайными параметрами, а ответы вычисляются программно. Вызова API языковой модели пока нет. Вкладка «Промпт» позволяет скопировать запрос для отдельного эксперимента с моделью. Отметка «Решено» устанавливается самим пользователем.

## Требования

- Node.js 18 или новее и npm.
- Python 3, доступный командой python. Он нужен для статического сервера и исполнения проверяемых учебных Python-примеров в тестах.

Внешних npm-зависимостей и отдельной сборки нет. Устанавливать пакеты для текущей версии не требуется.

## Запуск

В терминале из корня проекта:

```bash
npm run dev
```

Открой http://localhost:8000. Для остановки сервера нажми Ctrl+C.

Сервер можно запустить напрямую:

```bash
python -m http.server 8000 --directory dist
```

Если Python 3 установлен под именем python3, для прямого запуска замени python на python3. Для тестов команда python должна быть доступна в окружении.

## Проверки

```bash
npm test
```

Проверяются сочетания тем, уровней и количества заданий, детерминированное восстановление вариантов, математические ответы, исполнение учебных Python-фрагментов и события интерфейса. Проверки интерфейса выполняются через адаптер DOM; для проверки внешнего вида нужен отдельный запуск в браузере.

## Работа в Codex

Подключи этот репозиторий к окружению Codex. Сначала запусти npm test, затем npm run dev для просмотра приложения. Для текущей версии ключи API не нужны.

Следующий этап курсовой — серверное подключение языковой модели, проверка полученного JSON и сравнение нескольких вариантов промптов на одинаковых параметрах задания. API-ключи должны храниться в серверном окружении и не попадать в браузерный код или Git.

## Размещение

Папка dist содержит готовый статический сайт. Эта копия переносится из исходного проекта Sites без служебных настроек размещения и без изменения уже размещённой версии. Обновления репозитория сами по себе не обновляют первоначальный сайт. Способ дальнейшего размещения нужно настраивать отдельно с сохранением требуемого доступа.
